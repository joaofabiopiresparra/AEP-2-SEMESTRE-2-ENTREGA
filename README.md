## Sobre o projeto

O *PSE em Ação* é um sistema desenvolvido em linguagem C como parte da Atividade de Estudo Programada (AEP) do curso de Engenharia de Software da UniCesumar.

O projeto tem como objetivo auxiliar na organização e no acompanhamento de atividades do Programa Saúde na Escola (PSE), facilitando o registro de informações sobre as ações planejadas e realizadas.

A proposta é reunir essas informações em um único sistema, permitindo que as equipes escolares e de saúde acompanhem as atividades de forma mais organizada.

O sistema possui um menu com as seguintes opções:
